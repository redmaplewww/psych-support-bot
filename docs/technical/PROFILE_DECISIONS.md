# 画像记忆模块工程决策记录（ADR 摘要）

自进化用户画像（belief 流 + 质询闭环）的状态与边界约束。改代码前先读这里；
改约束时先改这里。知识提炼与维度设计见
[profile-memory-knowledge.md](../plans/profile-memory-knowledge.md)。

## P1. 画像归属与商业化分级（当前生效）

**决策**：画像归属用户本人，游客模式（`AUTH_ENABLED=false`，user_id 客户端
自报）下同样积累——接受"换设备/换 id 画像即分叉"的代价换取零门槛体验。
后期可将记忆模块分级作为消费锚点（免费/付费 tier 决定哪些记忆层开放）。

**护栏**：
- 分级只切**深度与洞察层**（趋势分析、机制洞察、长期轨迹）；安全链路
  （`RiskEvent` 结构化通道、safety_floor）永不入付费墙——架构上它本就在
  画像层之外，此条是把事实变成明文规则。
- 分级计量沿用 `UsageEvent` 伦理边界：只记动作，不记内容。
- 架构上分级 = `MEMORY_MODULE_*` 热插拔开关的 tier 映射，不新增机制。

## P2. 提取成本策略：先不设上限，全量统计（当前生效）

**决策**：画像提取调用前期**不设成本上限**（进化优先），但 K1 起必须
全量记录调用级统计；积累到足量后分析，选取记忆性能与用户体验的性价比
平衡点作为正式预算。

**统计字段（缺一不可）**：触发原因、模型、token、延迟、产出 claims 数、
以及**每条 claim 后续被确认/否决的结局**。决策指标是"每条被确认信念的
成本"，不是"每次调用的成本"——没有结局字段，数据攒了也定不了预算点。

**护栏**：保留稳定性熔断阀——worker 饱和时本轮跳过提取（fail-open）。
这是保护对话延迟的体验阀门（与语音 D1 单 worker 约束同源），不与
"成本不限量"冲突：P2 约束成本维度，熔断阀守体验维度。

## P3. 展示层词典化 + 拟人形象边界（当前生效）

**决策**：用户界面呈现的画像是一个拟人形象 + 下方友善的分类画像点，
**不使用心理学术语**。

**实现约束**：
- 内部 belief 永远存临床中性结构化语言（如 `mechanism: avoidance,
  target: social`），展示层经**词典映射**转生活化措辞（如"压力大的时候，
  你好像更想先躲一躲"）。术语不出存储层；词典是唯一渲染通道，禁止
  把 claim 原文直接透出。
- **D3 机制信念在用户经质询亲口认领之前，只在内部参与干预选择，不在
  面板展示**——未经认领的机制解读等于贴标签。
- **面板默认展示集（K0 词典层复核时补充，K3 落地时修订 D1 口径）**：
  D1（L2 直接出；L4 须过渲染水位 0.55 ≈ 两次跨轮证据——否则 K1 阶段
  面板会长期空白）、D4、D6、D7、D8；**D2 严重度轴默认不在面板展示**
  （最易触发标签焦虑，仅内部参与干预选择，是否开放留给 K3 用户验证）；
  D3 认领后展示。distortion.* 的 11 个 key 永不入词典（机器可校验）。
- 拟人形象是"**画像有了一张脸**"，不扮演有独立心智的角色：禁止"我觉得
  你……"式第一人称心智台词，与 role.md 既有 AI 非人边界一致；对脆弱
  用户需防过度依恋，形象的措辞归属始终是"系统对你观察的整理"。
